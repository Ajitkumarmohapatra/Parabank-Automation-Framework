# 🚀 Parabank Automation Framework

## 📌 Project Overview

This project is an end-to-end Selenium Automation Framework developed for the Parabank web application.

The framework follows the **Page Object Model (POM)** design pattern and is built using **Java, Selenium WebDriver, TestNG, and Maven**. It provides a clean, reusable, and maintainable automation structure for UI testing.

# ▶️ How to Run the Project

1. Clone the repository

```
git clone https://github.com/Ajitkumarmohapatra/Parabank-Automation-Framework.git
```

2. Import as Maven Project in Eclipse.

3. Update Maven Dependencies.

4. Execute:

```
testng.xml
```

or

Run the TestNG test suite.
